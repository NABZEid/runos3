# RunOS

Aplikasi lari Flutter (gaya Strava iOS): target jarak/waktu, timer, pace, jarak, kalori,
estimasi dehidrasi + catat minum, rute, split per km, streak harian, riwayat. Semua beranimasi.

## Cara pakai
1. Pasang Flutter, lalu jalankan `setup.bat` (Windows) atau `bash setup.sh`.
   Script ini membuat folder android/ios, memasang ikon dari logo RunOS (bukan logo Flutter),
   dan menambah izin lokasi.
2. `flutter run` (HP asli untuk GPS, atau aktifkan "Mode simulasi" di emulator).
3. APK: `flutter build apk --release`
